# New Features in FlowSpace 2.0

**Release Version:** 2.0  
**Product:** FlowSpace Project Management Platform

## Overview

FlowSpace 2.0 introduces new features that help teams organize tasks, monitor project progress, and manage project notifications more effectively.

This page describes the new functionality included in this release and explains how to use each feature.

## 1. Custom Dashboards

### What Is It?

Custom Dashboards allow users to create personalized views of important project information. Users can monitor task status, track project progress, and view relevant metrics from a single location.

### Key Benefits

- View important project information in one place.
- Customize dashboards based on individual needs.
- Monitor project progress without navigating between multiple pages.

### How to Use Custom Dashboards

1. Sign in to your FlowSpace account.
2. Navigate to the **Dashboards** section.
3. Select **Create Dashboard**.
4. Enter a name for your dashboard.
5. Add the available widgets you want to display.
6. Arrange the widgets according to your preferences.
7. Select **Save Dashboard** to save your changes.

### Expected Result

Your new dashboard displays the selected widgets and provides a consolidated view of relevant project information.

---

## 2. Advanced Task Filters

### What Is It?

Advanced Task Filters allow users to narrow down task lists using multiple criteria, making it easier to locate specific tasks in large projects.

### Available Filter Options

- **Assignee:** Find tasks assigned to a specific team member.
- **Priority:** Display tasks based on their priority level.
- **Status:** Filter tasks by status, such as To Do, In Progress, or Completed.
- **Due Date:** Find tasks based on their deadlines.

### How to Use Advanced Task Filters

1. Open the project you want to review.
2. Navigate to the **Tasks** section.
3. Select **Filters**.
4. Choose one or more filter criteria.
5. Select the required values for each criterion.
6. Apply the filters to update the task list.

### Expected Result

The task list displays tasks that match the selected filter criteria.

### Example

To find high-priority tasks assigned to a specific team member:

1. Set the **Priority** filter to High.
2. Select the team member under **Assignee**.
3. Apply the filters.

FlowSpace displays tasks matching both conditions.

## 3. Improved Notification Preferences

### What Is It?

Improved Notification Preferences allow users to customize which project activities trigger notifications.

### Key Benefits

- Receive updates relevant to your responsibilities.
- Reduce unnecessary notifications.
- Manage notification preferences for different activities.

### How to Configure Notification Preferences

1. Sign in to FlowSpace.
2. Open your profile menu.
3. Navigate to **Settings**.
4. Select **Notifications**.
5. Enable or disable the available notification categories.
6. Save your changes.

### Expected Result

FlowSpace applies your selected notification preferences to the supported notification categories.

**Note:** The exact notification categories and settings depend on the product configuration.
