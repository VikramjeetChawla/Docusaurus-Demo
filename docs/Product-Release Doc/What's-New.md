# What's New in FlowSpace 2.0

**Release Version:** 2.0  
**Release Date:** October 12, 2026  
**Product:** FlowSpace Project Management Platform

## Overview

FlowSpace 2.0 introduces new features and improvements designed to help teams organize projects, track progress, and collaborate more efficiently. This release includes customizable dashboards, advanced task filters, improved notification settings, and performance enhancements.

## Release Highlights

### 1. Custom Dashboards
Create personalized dashboards to monitor project progress, track task status, and view important project metrics in one place.

### 2. Advanced Task Filters
Find tasks more easily by filtering them based on assignee, priority, status, and due date.

### 3. Improved Notifications
Customize notification preferences to receive updates relevant to your projects and reduce unnecessary notifications.

### 4. Performance Improvements
Experience smoother navigation and improved responsiveness when working with large project boards.

- **Project Managers:** Monitor project progress through customizable dashboards.
- **Team Members:** Find relevant tasks faster using advanced filters.
- **Team Leads:** Stay informed about project activity through improved notifications.
