## Versioning Guidelines

FlowSpace uses a version number to identify each product release.

- **Major releases:** Introduce significant functionality or changes that may affect existing workflows.
- **Minor releases:** Introduce new features and enhancements.
- **Patch releases:** Primarily address bugs, security issues, or smaller maintenance changes.

These definitions are illustrative conventions for this portfolio project; actual versioning policies may differ between products.
