# Usage Guide

## Overview

This guide explains how to use Visual Studio Code (VS Code) for basic development tasks.

## Step 1: Open a Project

Open the terminal and navigate to your project directory.

```bash
cd path/to/project
code .
Step 2: Create a File
Create a new file using the Explorer panel or the New File option. Choose the appropriate file extension, such as .py, .js, or .html.

Step 3: Write Code
Open the file in the editor and start writing your code.

Step 4: Run Your Code
Open the integrated terminal using Ctrl + ` and execute the appropriate command for your programming language.

For example, to run a Python file:

bash
python3 main.py
Step 5: Save Your Work
Press Ctrl + S to save your changes.

Step 6: Use Extensions
Install extensions to add language support, debugging tools, formatting, and other useful features.

Conclusion
VS Code provides a simple environment for writing, editing, running, and debugging code. Its integrated terminal and extensions make development easier and more efficient.
